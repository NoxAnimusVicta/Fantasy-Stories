# The Lich King’s War · Companion

[Open the companion](https://noxanimusvicta.github.io/Fantasy-Stories/companion/). In Safari choose Share → Add to Home Screen. The app loads its player-facing record from [campaign.json](campaign.json). Character displays the current outfit. Story retains the arrival portrait under The fallen pine. The recordedThrough field identifies the last enacted exchange included in the release. Deploy only the app assets to gh-pages after updating main.
